# Учебный журнал студентов

Консольное приложение для ведения небольшого списка студентов. Сейчас можно добавлять записи, показывать список и искать студентов по имени, специальности или группе.

## Цель

Создать простой учебный пример для практики управления версиями и командной разработки через Git и GitHub.

## Функции

- регистрация студента: имя, специальность, учебная группа и средний балл;
- проверка обязательных полей и диапазона балла от 0 до 100;
- просмотр добавленных записей;
- поиск по имени, специальности или группе без учёта регистра.

Сортировка и постоянное хранение данных рассматриваются как следующие задачи.

## Технологии

- C#;
- .NET 10 SDK;
- Git и GitHub.

## Запуск

```powershell
dotnet run --project StudentGradebook.csproj
```

Введите данные студента по приглашениям программы. Пустое имя завершает ввод и показывает список. Затем можно найти совпадения по одному из поддерживаемых полей.
