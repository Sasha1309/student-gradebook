# GitHub Issues

Шесть Issues созданы в репозитории. GitHub назначил номера по фактическому порядку создания:

1. **Определить модель данных студента** — определить имя, специальность, группу и средний балл. Готово, когда тип Student хранит эти значения и документирует публичные члены.
2. **Добавить студента с проверкой ввода** — реализовать ввод и проверку имени, группы и балла. Готово, когда допустимые записи добавляются, а некорректные значения отклоняются.
3. **Показывать список студентов** — вывести все добавленные записи с основными полями. Готово, когда список отображается в читаемом формате.
4. **Документировать проект и подготовить v0.1.0** — актуализировать README, CHANGELOG и создать тег версии. Готово, когда описание соответствует коду и тег указывает на стабильную версию.
5. **Искать студентов по полям** — поиск по имени, специальности и группе без учёта регистра. Готово, когда совпадения выводятся, а пустой результат явно сообщается.
6. **Сортировать по среднему баллу** — добавить выбор направления сортировки. Готово, когда список выводится по возрастанию или убыванию оценки.

В рамках практической работы в отдельных ветках реализованы задачи #2 и #5. Задачи #1, #3 и #4 входят в объём документации/PERT; сортировка (#6) оставлена следующей итерации.
