# Changelog

## [0.1.0] — 2026-11-24

### Added
- Добавление студента с проверкой обязательных полей и среднего балла.
- Просмотр списка студентов.
- Поиск по имени, специальности и группе без учёта регистра.
- Документация публичных типов и методов, описание проекта, WBS и расчёты PERT.

### Ограничения
- Данные хранятся только в памяти и теряются при завершении приложения.
- Интерфейс доступен только в консоли.
- Сортировка по среднему баллу пока не реализована.
