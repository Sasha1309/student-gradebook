# WBS — учебный журнал студентов

1. Управление записями студентов
   - #1 Определить модель данных студента.
   - #2 Добавлять студента и проверять введённые значения.
   - #3 Показывать список студентов.
2. Поиск и представление данных
   - #5 Искать студентов по имени, специальности или группе.
   - #6 Сортировать список по среднему баллу.
3. Документация и выпуск
   - #4 Описать проект и подготовить версию 0.1.0.

GitHub присвоил номера Issues в порядке создания: #1 модель, #2 добавление, #3 список, #4 документация, #5 поиск, #6 сортировка.
